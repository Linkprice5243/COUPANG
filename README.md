# 쿠팡 광고 운영 전략 제안서

쿠팡 광고 제안서를 웹페이지 형태로 구성한 GitHub Pages용 정적 웹사이트입니다.

## 파일 구성
- `index.html` : 제안서 본문
- `style.css` : 쿠팡 레드 계열의 UI/반응형 디자인
- `script.js` : 스크롤 진행률, 목차 활성화, 모바일 메뉴

## GitHub Pages 배포
1. GitHub에서 새 Repository 생성
2. `index.html`, `style.css`, `script.js` 업로드
3. Repository의 `Settings → Pages`
4. `Deploy from a branch` 선택
5. `main` / `root` 선택 후 저장
6. 생성된 Pages 주소로 접속

※ 실제 쿠팡 브랜드 CI와 동일한 디자인을 복제하지 않고, 쿠팡의 대표적인 레드 톤을 참고한 제안서 스타일입니다.


## 키보드 페이지 이동
- `↓` / `Page Down` : 다음 섹션
- `↑` / `Page Up` : 이전 섹션
- 모바일에서는 기존 스크롤/목차를 사용

## 레퍼런스 반영
현재 `08. 레퍼런스 반영 예정` 섹션을 만들어 두었습니다. 이후 전달하는 레퍼런스의 목차, 페이지 흐름, 디자인 톤을 기준으로 전체 제안서 구조를 재편집할 수 있습니다.
